# 💰 나만의 용돈 기입장 프로그램 (Budget App)

별도의 추가 설치 없이 파이썬 기본 기능만으로 만든 안전하고 빠른 콘솔 가계부 프로그램입니다.

---

## 📋 1. 프로그램 구조와 동작 원리

### (1) 역할을 나눠서 5개 파일로 쪼갠 이유
코드를 한 파일에 다 몰아넣지 않고 역할에 따라 나누었습니다.

```
budget_app/
├── models.py      # 데이터 모양 정의 (가계부 한 줄이 어떻게 생겼는지)
├── storage.py     # 파일 저장 및 읽기 (하드디스크에 파일 쓰고 불러오기)
├── services.py    # 핵심 기능 및 계산 (추가/삭제/검사/통계 계산)
├── decorators.py  # 에러 숨기기 및 실행 시간 측정
└── cli.py         # 화면 입력 및 출력 (사용자와 대화하는 창구)
```

- **왜 나눴을까?**: 나중에 터미널 창 대신 스마트폰 화면이나 웹사이트로 바꾸더라도, 핵심 기능(`services.py`)과 파일 저장 방식(`storage.py`)을 그대로 재사용할 수 있도록 하기 위해서입니다.
- **모듈 확인 명령어**:
```bash
python -c "import budget_app"
```

### (2) 클래스별 역할 분담
- **`Transaction` / `Budget` (데이터 틀)**: 거래 내역과 예산이 어떤 모양으로 생겼는지 틀을 잡고, 파이썬 객체와 파일 저장용 데이터로 서로 바꿔주는 역할을 합니다.
- **`StorageManager` (창고 관리자)**: 실제 파일 3개(`transactions.jsonl`, `categories.jsonl`, `budgets.jsonl`)를 열고, 닫고, 저장하는 작업만 전담합니다.
- **`BudgetService` (매니저)**: 날짜가 틀렸는지, 금액이 마이너스는 아닌지 검사하고, 이달의 수입과 지출을 계산하는 핵심 규칙을 처리합니다.

### (3) 데이터 수정/삭제 시 안전장치
- **임시 파일 교체 방식**: 파일을 직접 열어서 고치다가 컴퓨터가 갑자기 꺼지면 파일 전체가 망가질 수 있습니다. 그래서 **새 임시 파일에 먼저 완벽히 적은 뒤, 원래 파일과 순식간에 맞바꾸는 원자적 교체 방식**을 썼습니다.
- **자동 백업 파일(`.bak`) 생성**: 파일을 바꾸기 바로 직전에 원본 파일을 `.bak`이라는 백업 파일로 복사해 두어 문제가 생겨도 즉시 되돌릴 수 있습니다.
- **백업 동작 확인 명령어 및 실제 로그**:
```bash
# 내역 수정 실행
% python -m budget_app update --id TX-000001 --amount 15000 --memo "점심(특식)"
[수정 완료] TX-000001 | 2026-09-04 | expense | 식비       |    15000원 | 점심(특식)     [점심, 외식]

# 백업 파일 자동 생성 확인 
% ls -l data/transactions.jsonl.bak
-rw-r--r--  1 hohojooho0306  hohojooho0306  289 Sep  5 11:10 data/transactions.jsonl.bak
```

## 🐍 2. Python 핵심 기술 적용

### (1) 한 줄씩 읽어오는 방식 (제너레이터 스트리밍)
- **어떻게 동작할까?**: 10만 줄짜리 큰 파일이라도 파일 전체를 메모리에 한 번에 다 불러오지 않고, `yield`라는 문법을 써서 **딱 필요한 만큼만 한 줄씩 읽어서 화면에 보여줍니다.**
- **왜 좋을까?**: 파일 용량이 아무리 커져도 컴퓨터 메모리를 거의 쓰지 않아서 컴퓨터가 버벅거리지 않고 빠릅니다.
- **확인 명령어 및 실제 로그**:
```bash
# 최근 거래 내역 중 상위 5개만 조회
% python -m budget_app list --limit 5
TX-000002 | 2026-09-05 | income  | 월급       |   100000원 | 장학금          [장학금]
TX-000001 | 2026-09-04 | expense | 식비       |    15000원 | 점심(특식)     [점심, 외식]

# 카테고리가 '식비'인 것만 필터링 검색
% python -m budget_app search --category 식비
TX-000001 | 2026-09-04 | expense | 식비       |    15000원 | 점심(특식)     [점심, 외식]
```

### (2) 반복 기능을 묶어주는 도구 (데코레이터)
- **적용된 기능 3가지**:
  1. `@handle_cli_errors`: 영문 에러가 터미널에 길게 쏟아지지 않게 막아주고, "어디가 틀렸는지 + 어떻게 고치는지" 한글 힌트를 띄워줍니다.
  2. `@log_execution`: 함수가 실행될 때 어떤 데이터를 가지고 실행됐는지 기록을 남깁니다.
  3. `@measure_time`: 이 작업이 몇 초(밀리초) 만에 끝났는지 속도를 재어줍니다.
- **왜 썼을까?**: 에러 처리나 시간 측정 코드를 모든 함수마다 복사-붙여넣기 하지 않고, 이름표 하나만 달아서 깔끔하게 재사용하기 위해서입니다.
- **확인 명령어**:
```bash
# 시간 측정이 같이 뜨는지 확인 (디버그 모드)
BUDGET_DEBUG=1 python -m budget_app list
```

### (3) 데이터 타입 표시 (타입 힌트)
- **실제 코드 예시**:
```python
def search_transactions(
    self,
    from_date: Optional[str] = None,
    category: Optional[str] = None,
    type_: Optional[str] = None,
) -> Generator[Transaction, None, None]: ...
```
- **왜 좋을까?**: 코드를 읽을 때 "여기에 문자열이 들어가는지, 숫자가 들어가는지, 결과로 뭐가 나오는지" 헷갈리지 않고 바로 알 수 있어 실수를 방지합니다.

## 💾 3. 저장 방식과 큰 파일 대비 설계

### (1) JSONL 파일과 CSV 파일 비교

| 비교 항목 | JSONL (.jsonl) [프로그램 내부 저장용] | CSV (.csv) [외부 공유용] |
| :--- | :--- | :--- |
| **줄바꿈 메모** | 메모 안에 엔터(줄바꿈)가 많아도 절대 안 깨짐 | 메모에 엔터가 들어가면 줄 구분이 망가질 수 있음 |
| **복잡한 데이터** | 여러 개의 태그 `['점심', '외식']`를 그대로 저장 가능 | 태그를 쉼표로 따로 쪼개야 해서 번거로움 |
| **고장 격리** | 한 줄이 고장 나도 나머지 줄은 아무 문제 없이 읽음 | 윗부분이 고장 나면 파일 전체를 못 읽을 수 있음 |
| **편리함** | 메모장으로 보기 편함 | 엑셀 프로그램에서 바로 열림 |

- **선택 이유**: 가계부 데이터가 중간에 깨지지 않고 안전하게 보관하기 위해 프로그램 내부 저장에는 **JSONL**을 썼고, 사용자가 엑셀로 내보내서 볼 수 있도록 **CSV** 기능도 같이 넣었습니다.

### (2) 데이터가 10만 개 이상으로 커질 때 해결책
1. **정렬 속도 문제**: 10만 개를 한 번에 정렬하면 느려지므로, **지금 화면에 보여줄 10개만 똑똑하게 골라내는 방식(`heapq`)**을 적용했습니다.
2. **검색 속도 문제**: 10만 줄을 처음부터 끝까지 다 읽으면 오래 걸리므로, 책의 '목차'처럼 위치를 바로 찾아주는 색인(인덱스) 파일을 만들거나 전용 데이터베이스(SQLite)로 바꾸면 해결됩니다.
3. **수정/삭제 속도 문제**: 1줄 고치려고 10만 줄 전체를 다시 저장하는 것은 비효율적이므로, 바뀐 내용만 파일 끝에 추가하고 나중에 몰아서 정리하는 방식을 쓰면 해결됩니다.

### (3) CSV 가져오기(Import) 시 잘못된 데이터 처리
- **기본 방식 (안전한 것만 저장)**: 날짜가 이상하거나 카테고리가 없는 이상한 줄은 알아서 건너뛰고, 정상적인 데이터만 저장한 뒤 "몇 개 성공, 몇 개 실패"를 알려줍니다.
- **엄격한 방식 (`--strict`)**: 단 1줄이라도 잘못된 데이터가 섞여 있으면, 데이터가 꼬이지 않도록 파일 저장을 아예 취소하고 원래대로 되돌립니다.
- **확인 명령어**:
```bash
# 정상 데이터만 쏙 골라서 가져오기
python -m budget_app import --from data.csv

# 하나라도 틀리면 전부 취소하기
python -m budget_app import --from data.csv --strict
```

## 🎁 5. 추가 보너스 구현 기능

1. **파일 보호(원자적 저장)**: 수정 중에 꺼져도 데이터가 깨지지 않게 임시 파일로 교체하는 안전 기술 적용
2. **콘솔 표 정렬**: 외부 라이브러리 없이 글자 칸수를 딱딱 맞춰 표 형태로 보기 좋게 출력
3. **대체 카테고리 전환**: 카테고리를 지울 때 연결된 내역을 다른 카테고리로 한꺼번에 옮겨주는 기능(`--replace-with`) 추가
4. **원본 백업(`.bak`)**: 수정/삭제할 때마다 직전 파일 복사본을 자동으로 남겨둠
